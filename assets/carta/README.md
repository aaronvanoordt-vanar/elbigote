# Carta

Carpeta opcional, para las imágenes de la carta (PNG o PDF) si el negocio quiere
adjuntarlas además del texto de la web.

Lo recomendable es mantener la carta **como texto** en `index.html`: Google no lee
los precios dentro de una imagen, y en móvil una carta en PNG obliga a hacer zoom.
Ver la sección 3 de `CONTENIDO.md`.

Si aun así se quieren enlazar, dejar los archivos aquí y añadir el enlace desde la
nota al pie de la sección Carta.
